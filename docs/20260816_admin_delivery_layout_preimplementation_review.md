## 2. 现状调查

管理员交付区域上限为1180px，右侧详情固定330px，左侧表格同时设定`min-width: 880px`。当ASRAY账号列追加后，可用宽度小于表格最小宽度，因此出现水平滚动条、首列裁切以及当前滚动位置不明确。右侧330px内同时容纳长链接、复制按钮和三个状态操作，视觉层级过密。

## 3. 设计决定

| 区分 | 决定 |
|---|---|
| 宽屏容器 | 管理员摘要、母版、新建交付、交付管理及系统说明统一为最大1360px |
| 宽屏分栏 | 一览使用剩余宽度，详情为360～380px固定范围，间隔24px |
| 表格 | 取消宽屏强制880px最小宽度，使用固定列比例；编号和账号允许安全换行 |
| 中等宽度 | 1280px以下一览占满宽度，详情通过底部抽屉显示 |
| 详情链接 | 链接输入框占据整行，“复制链接／新窗口打开”在下一行等宽表示 |
| 状态操作 | “延长／重新发放”同行，“停止链接”独立一行并使用警示色 |
| 手机 | 760px以下继续使用既有Card一览和底部详情层 |

本次不改变API、DB、ASRAY开户、商品权限、密码、下载、交付状态及审计逻辑。

## 4. 制造前Review指摘

| ID | 重要度 | 指摘 | 设计对应 | 状态 |
|---|---|---|---|---|
| RV-DLV-048 | Major | 表格最小宽度大于左栏可用宽度，必然产生横向滚动 | 扩大工作区并改为固定列比例 | 対応予定 |
| RV-DLV-049 | Major | 首列长编号在水平滚动后不易识别当前记录 | 首列保留最大比例并允许换行 | 対応予定 |
| RV-DLV-050 | Medium | 330px详情内链接与多操作同行显示，信息层级不清 | 链接、复制操作和状态操作分行 | 対応予定 |
| RV-DLV-051 | Medium | 中等宽度仍保留双栏时左右两侧均过窄 | 1280px以下切换为全宽一览与详情抽屉 | 対応予定 |

## 5. 验收条件

1. 1440px宽度时交付一览无水平滚动，首列和ASRAY账号可识别。
2. 1180px宽度时一览为全宽，点击详情后以抽屉表示。
3. 760px以下继续使用Card一览，不产生页面水平滚动。
4. 详情的账号、链接和状态操作无重叠、裁切或越界。
5. React生产构建、Docker重建与本地浏览器验证通过。

正式TLS、正式客服UAT与生产Go／No-Go不在本次Local Layout改善范围内，继续保持`未実施`／`未判定`。
