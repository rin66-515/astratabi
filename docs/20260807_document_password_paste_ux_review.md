# 资料密码复制粘贴UX Review・测试记录

## 1. 对象与目标

- 对象：专属取件处的资料密码、确认密码和提交控制
- 目标：复制粘贴行为可理解、非法字符可定位、密码值不被页面擅自修改
- 非对象：密码规则变更、资料生成逻辑、ASRAY登录密码、数据库结构

## 2. 调查结果

React没有阻止`paste`事件，异常体验来自反馈不足：两个输入框缺少独立字段身份，同为密码自动填充对象；遮挡状态下无法核对内容；两次不一致或包含全角字符时，提交按钮只会禁用或等待后端返回，客户不知道原因。

## 3. 修正内容

| ID | 内容 | 安全边界 |
|---|---|---|
| UX-PW-01 | 两个输入框追加独立`id`、`name`、label及自动填充属性 | 不改变API Payload |
| UX-PW-02 | 两个输入框同步显示/隐藏 | 默认仍为遮挡状态 |
| UX-PW-03 | 粘贴后显示目标字段、字符数和非法字符有无 | 不显示或保存密码原文 |
| UX-PW-04 | 即时显示长度、半角、字母、数字、一致性 | 与后端规则一致 |
| UX-PW-05 | 非法或不一致时设置`aria-invalid`并禁用生成 | 后端仍重复校验 |

## 4. 实施结果

| Case | 操作 | 期待结果 | 结果 |
|---|---|---|---|
| UX-PW-T01 | 13位半角英数字符号分别粘贴到两个框 | 粘贴位数正确、5项通过、按钮启用 | 合格 |
| UX-PW-T02 | 粘贴含空格和全角数字的内容 | 提示非法字符、半角规则失败、按钮禁用 | 合格 |
| UX-PW-T03 | 两次输入不同 | 确认框无效、一致性失败、按钮禁用 | 合格 |
| UX-PW-T04 | 输入汉字且两次相同 | 半角规则失败、按钮禁用 | 合格 |
| UX-PW-T05 | 点击显示/隐藏 | 两个字段同步在`password`/`text`间切换 | 合格 |

验证环境为本地Docker取件页面。执行TypeScript/Vite Build与容器Build，浏览器测试未提交资料生成请求。正式移动端实机、第三方密码管理器组合及正式客户UAT仍未实施。
