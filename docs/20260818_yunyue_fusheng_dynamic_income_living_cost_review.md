## 2. 收入与生活成本模型

工资仍保留 `salaryJpy` 作为最终结果，底层改为：

```text
基础工资
+ 职责津贴
+ Mentor津贴
+ 加班及其他收入
= 本月工资
```

- 每6个月复核一次。
- 按 WorkTrust、Tech、Workplace 与 Mentor 职责计算 `0 / 5,000 / 10,000 / 15,000 JPY`。
- 未达到条件时只记录本次复核，不保证涨薪。
- Mentor 津贴为 `8,000 JPY / month`，持续期间 AP 修正 `-1`。

生活支出改为房租、饮食、水电、通信、交通、烟草和其他基本支出。饮食档位可每月选择，默认继承上月。

| 饮食档位 | 月支出 | 主要方向 |
|---|---:|---|
| survival | 28,000 | Health / RecoveryDebt / LifePoverty 风险 |
| frugal | 42,000 | 中性基准 |
| balanced | 65,000 | Health / Mental 恢复 |
| comfortable | 90,000 | Mental / 生活感提高，现金压力增加 |

默认 `smokingLevel = regular`，基础烟草支出为 `16,000 JPY / month`。压力性吸烟和一天两包会作为当月额外烟草支出进入同一张月结，不在 UI 中硬编码。

## 3. 最小正式事件

本 Slice 只增加4个事件，正式月度事件由15个变为19个：

1. “新人就麻烦你带一下了”——职责、津贴与 AP 代价入口。
2. “下午的第二包”——高压力下的短期缓解与长期代价。
3. “没有数完的一天”——一天两包的低概率后续事件。
4. “胃先提出了意见”——连续 survival + RecoveryDebt 的身体提醒。

- 全部为中日双语。
- 全部至少保留一个普通现实选项。
- 事件只受状态和隐藏变量影响权重，不做必然触发。
- 没有道德说教，也没有新增戒烟系统。

## 4. 月度生命周期

```text
月初恢复
↓
工资复核 / Mentor确认
↓
固定本月收入与生活方式快照
↓
月度事件
↓
饮食选择 / 自由行动 / 额外还款
↓
动态工资与生活支出
↓
最低还款 / 额外还款
↓
AP Consequence + 饮食 / 吸烟效果
↓
原有 Ending Resolver
```

额外还款上限会随本月饮食与烟草费用重新计算；从节省切换为舒适饮食时，系统会同步收紧可追加还款金额。

## 7. 平衡判定

- 极限省钱比正常饮食少支出，清债更快，但24个月 Health 为53、LifePoverty 为60，代价明确。
- 正常饮食显著改善 Health / Mental / RecoveryDebt，但24个月内没有完成额外清债，符合“更稳定但更慢”。
- 舒适饮食主要改善 Mental 和生活感，不构成经济最优解。
- 高压力吸烟依靠高透支副业收入快速清债，但 Health 3、Mental 0、Stress / RecoveryDebt 100、负AP 23个月，不构成胜利路线。
- 工资成长收入高于基准，但与 balanced 生活升级同时发生，实际清债改善被生活成本部分抵消。
- Mentor 有稳定津贴，同时承担持续 AP -1；没有形成无代价 Buff。

### 基准变化

默认 regular 烟草支出加入后：

- 最差固定汇率单元路线：第23月 → 第26月。
- 固定种子500回零额外还款路线：24个月清债率86%，清债中位第24月。

变化原因是每月新增真实烟草支出，不是 Side Hustle、利率、最低还款或 Ending 规则变化。结果仍落在约定的约20～26月范围，因此没有为了强守第23月反向调低其他成本。

## 9. 剩余风险

- 正式事件仍为一次性事件；压力性吸烟当前用于验证触发与成本链，不是完整可重复习惯系统。
- `overtimeIncomeJpy` 和 `roleAllowanceJpy` 已有正式明细接口，本 Slice 默认仍为0，未扩加班玩法。
- 默认吸烟状态会使旧存档未来现金流发生变化；历史月结不会被反向改写。
- 390px 浏览器移动宽度已确认无横向溢出；真实手机实体设备尚未执行。
