# AstraTabi Portal 项目说明目录

更新时间：2026-08-07

适用仓库：`astratabi-portal`

适用分支：`main`

## 1. 目的

本目录集中说明云月小铺公开站与 ASRAY 资料交付后台目前已经具备的能力、尚未完成的范围，以及从制造到正式发布的推进顺序。

本目录是项目状态和计划的入口，不代替各机能基本设计书、详细设计书、API 定义书、DB 定义书和测试式样书。后续进入正式制造时，应从这里链接到对应成果物，并同步更新状态。

## 2. 状态标记

| 标记 | 含义 | 使用条件 |
|---|---|---|
| `実装済` | 已实现 | 可以从当前代码、配置或数据库迁移中确认 |
| `設計確定` | 设计已确定 | 业务规则已经确认，但代码或测试尚未完成 |
| `設計提案` | 设计提案 | 推荐方案，仍可能因实现调查或运营决策调整 |
| `未実装` | 未实现 | 当前代码尚不具备该能力 |
| `未試験` | 未测试 | 尚无对应测试及证迹 |
| `対象外` | 本期范围外 | 当前发布不计划实现 |

状态必须以仓库证据和测试证迹为准。不得把页面占位、模拟数据、设计说明或 API 外形误记为完成。

## 3. 阅读顺序

1. [01_CURRENT_IMPLEMENTATION.md](01_CURRENT_IMPLEMENTATION.md)：确认当前系统实际能做什么。
2. [02_ROADMAP.md](02_ROADMAP.md)：确认下一阶段的制造顺序和完成条件。
3. [03_OPERATION_AND_RELEASE.md](03_OPERATION_AND_RELEASE.md)：确认本地、正式环境、备份和发布边界。
4. [04_DECISION_LOG.md](04_DECISION_LOG.md)：确认已经敲定与仍待决定的事项。
5. [../delivery-backend-basic-design.md](../delivery-backend-basic-design.md)：查阅现有交付后台基本设计。

## 4. 当前结论

- 云月小铺公开站、客户领取页面、中文单管理员后台及本地 Docker 三容器环境：`実装済`。
- 管理员认证、交付记录、令牌摘要、下载次数、审计、母版 ZIP 上传和 SHA-256 校验：`実装済`。
- 客户专属 Excel 水印副本、交付 ZIP/摘要生成、真实文件流、重新发放履历、定时备份和正式服务器部署：`未実装`。
- 微信人工收款后由客服发放链接：`設計確定`；支付平台 API、购物车和客户账号：`対象外`。

## 5. 更新规则

- 每个机能制造开始前，把对应条目从 `設計提案` 调整为 `設計確定`。
- 代码合并但测试未完成时，保持 `未試験`，不可直接写为发布完成。
- 单体、结合、综合和发布确认全部完成后，再更新本目录和各设计/测试台账。
- 需求、设计、实现或测试发生偏差时，在 `04_DECISION_LOG.md` 记录原因、影响范围和处理结果。
