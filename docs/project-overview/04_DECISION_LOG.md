## 4. 变更记录规则

新增决策时必须记录：

- 决策 ID、日期和决策内容。
- 需求来源与选择理由。
- 影响的画面、API、表、Batch、测试和运维手顺。
- 是否需要数据迁移或旧交付兼容。
- 实装、测试、Review 和发布状态。

实际 Review、测试和验收只能记录真实执行结果；未执行时使用 `未レビュー`、`未試験`、`未承認` 或 `未判定`，不得生成虚假通过记录。
