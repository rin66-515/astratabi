# 《灯未眠》v1 试听稿

- 用途：云月小铺前台背景音乐候选
- 形式：原创无歌词器乐循环
- 速度：68 BPM，4/4 拍
- 调式：D 小调五声音阶为主
- 时长：约 1 分 53 秒
- 声部：箫意象主旋律、古琴意象拨弦、暖色持续音、极轻木音与风声
- 状态：旋律和气质确认用合成小样，尚未接入网站

## 段落

1. 门外（1-4 小节）：疏淡气息与灯影。
2. 入铺（5-12 小节）：第一次出现完整主题。
3. 见月（13-20 小节）：旋律向高处展开。
4. 归灯（21-28 小节）：主题变化后回落。
5. 夜未尽（29-32 小节）：只余风、弦与两声箫，接回开头。

## 原创边界

旋律、和声与编排从零创作，不采样、不引用《什么是逍遥》或其他现有歌曲的录音与旋律。本稿使用程序合成音色，后续可以用真实吉他、箫、古琴或其他乐器重新录制。
